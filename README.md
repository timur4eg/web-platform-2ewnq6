# Google Chat Bot

Современный веб-чат-бот с красивым интерфейсом и множеством функций, вдохновленный Google Assistant.

## 🚀 Возможности

### Основные функции
- 💬 **Чат с ботом** - общение на русском языке
- 🎤 **Голосовой ввод** - распознавание речи (поддерживается в современных браузерах)
- ⚡ **Быстрые действия** - кнопки для быстрого доступа к функциям
- 🎨 **Настройки** - персонализация имени бота, темы и звуков
- 💾 **Сохранение истории** - все сообщения сохраняются в браузере
- 🌙 **Темная тема** - поддержка светлой, темной и автоматической темы

### Команды бота
- `привет` / `здравствуй` - приветствие
- `как дела` / `как ты` - справка о состоянии бота
- `время` / `который час` - показать текущее время
- `дата` / `число` - показать текущую дату
- `погода` - информация о погоде (заглушка)
- `шутка` / `анекдот` - рассказать случайную шутку
- `помощь` / `help` - показать список возможностей
- `спасибо` / `благодарю` - ответ на благодарность
- `пока` / `до свидания` - прощание

### Быстрые действия
- 🌤️ **Погода** - информация о погоде
- 🕐 **Время** - показать текущее время
- 😄 **Шутка** - рассказать случайную шутку
- ❓ **Помощь** - показать справку

## 🛠️ Технологии

- **HTML5** - структура интерфейса
- **CSS3** - стилизация и анимации
- **JavaScript (ES6+)** - логика и функциональность
- **Web Speech API** - голосовой ввод
- **Web Audio API** - звуковые уведомления
- **LocalStorage** - сохранение данных

Чат-бот полностью адаптивен и работает на всех устройствах:
- 📱 Мобильные телефоны
- 📱 Планшеты
- 💻 Настольные компьютеры

- Градиентные цвета в стиле Google

## 🚀 Запуск

1. Откройте файл `index.html` в любом современном браузере
2. Начните общение с ботом!

### Требования к браузеру
- Chrome 66+ (для голосового ввода)
- Firefox 60+
- Safari 11+
- Edge 79+

## ⚙️ Настройки

### Доступные настройки:
- **Имя бота** - измените имя ассистента
- **Тема** - выберите светлую, темную или автоматическую тему
- **Звуковые уведомления** - включите/выключите звуки

### Как открыть настройки:
1. Нажмите на иконку шестеренки в заголовке чата
2. Измените нужные параметры
3. Настройки сохраняются автоматически

## 💾 Сохранение данных

Все данные сохраняются в localStorage браузера:
- История сообщений (последние 50)
- Настройки пользователя
- Имя бота

## 🔧 Кастомизация

### Добавление новых команд
Отредактируйте метод `processUserMessage()` в файле `script.js`:

```javascript
else if (lowerMessage.includes('ваша команда')) {
    response = 'Ваш ответ';
}
```

### Добавление новых шуток
Добавьте шутки в массив `jokes` в методе `getRandomJoke()`:

```javascript
const jokes = [
    // существующие шутки...
    "Ваша новая шутка"
];
```

### Изменение стилей
Отредактируйте файл `styles.css` для изменения внешнего вида.

## 🐛 Известные ограничения

- Голосовой ввод работает только в HTTPS или localhost
- Некоторые браузеры могут требовать разрешения на доступ к микрофону
- Звуковые уведомления могут не работать в некоторых браузерах
